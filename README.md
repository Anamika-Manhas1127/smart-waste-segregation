## EcoSort – Smart Waste Segregation System

EcoSort is a web-based smart waste segregation system designed to help users identify different types of everyday waste and learn how to dispose of them responsibly.

The project aims to promote proper waste management, reduce improper disposal, and encourage environmentally friendly habits through a simple and interactive user interface.

-> Project Overview

Waste segregation is an important step toward recycling, composting, and reducing the amount of waste sent to landfills. EcoSort provides a user-friendly platform that helps users understand waste categories and make more informed disposal decisions.

-> Features

- **Waste Identification:** Helps users identify waste categories using the information provided by the application.
- **Waste Segregation Guide:** Provides guidance on sorting everyday waste into appropriate categories.
- **Search Functionality:** Allows users to search for waste items, if supported by the current implementation.
- **Disposal Instructions:** Offers relevant disposal guidance and examples.
- **Interactive Interface:** Designed to make learning about waste management simple and accessible.
- **Responsive Design:** Built with web technologies for use in modern browsers.

-> Technologies Used

- **HTML5** – Structures the web application.
- **CSS3** – Provides styling, layout, and visual design.
- **JavaScript** – Supports application logic and interactive functionality.
